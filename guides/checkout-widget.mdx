---
title: "Checkout widget"
description: "Let buyers pin their location and see the UrbnBox delivery fee in your own checkout."
---

The widget sits in your checkout. The buyer searches for their estate or street, or uses their location, and can fine-tune the pin on a map. The widget shows the delivery fee and your delivery promise, then writes a quote into your checkout form. After the buyer pays, your server books the order with that quote.

It is plain JavaScript in a Shadow DOM, about 5 KB gzipped, in English or Swahili. The map only loads if the buyer asks for it.

## Before you start

You need:

- A **publishable** key (`dpk_live_` or `dpk_test_`) with your checkout's website listed on it, for example `https://shop.example.com`. Add staging sites too. Make it under **Integrations** in the portal.
- A **secret** key (`dk_`) on your server for booking.
- Your dispatch point and delivery promise, saved on the portal's **Checkout widget** page. Every quote is measured from that point.

<Warning>
  Never put a secret key in the page. The publishable key can only ask for prices, and only from the websites on its list.
</Warning>

## Add it to your checkout

```html
<div id="urbnbox-delivery"></div>

<script
  src="https://portal.urbnbox.io/widget/v2.js"
  data-key="dpk_live_..."
  data-mount="#urbnbox-delivery"
  data-form="#checkout"
  data-cart-weight-kg="2.5"
  async></script>
```

You can also put the settings on the mount element itself, `<div data-urbnbox-delivery data-key="dpk_live_..." data-form="#checkout"></div>`, which is handy when the script tag is shared across pages.

| Setting | Required | What it does |
| --- | --- | --- |
| `data-key` | Yes | Your publishable key |
| `data-mount` | On the script tag | Where to draw the widget |
| `data-form` | No | The checkout form to write the quote into |
| `data-cart-weight-kg` | No | Cart weight. Up to 120 kg goes by motorbike, up to 1,000 kg by van; heavier carts are not offered delivery |
| `data-lang` | No | `en` (default) or `sw` |
| `data-accent`, `data-radius`, `data-font` | No | Match your shop's colour, corner radius and font |
| `data-callback` | No | Name of a global function to call with each quote |

## What lands in your form

When the buyer has a price, the widget adds hidden inputs to your form:

| Field | Value |
| --- | --- |
| `urbnbox_quote_id` | The quote to book with |
| `urbnbox_fee_kes` | The fee shown to the buyer, in whole KES |
| `urbnbox_address`, `urbnbox_lat`, `urbnbox_lng` | Where the buyer pinned |
| `urbnbox_fee_paid` | `false`: the buyer pays the driver on delivery |

If the buyer is outside the area UrbnBox covers, the fields are cleared and the widget says so.

## Building your total in JavaScript

```html
<script src="https://portal.urbnbox.io/widget/v2.js" async></script>
<script>
  window.addEventListener('load', function () {
    UrbnBox.delivery({
      key: 'dpk_live_...',
      mount: '#urbnbox-delivery',
      cart: { weightKg: 2.5 },
      onQuote: function (q) { /* q.quoteId, q.feeKes, q.address, q.lat, q.lng */ },
      onUnavailable: function (info) { /* info.message */ }
    });
  });
</script>
```

The widget also fires a bubbling `urbnbox:quote` event on its mount element.

## Book when the buyer has paid

From your server, send the quote with the buyer's details:

```bash
curl https://portal.urbnbox.io/api/v2/orders \
  -H "X-API-Key: $URBNBOX_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "quote_id": "<urbnbox_quote_id from the form>",
    "reference": "ORDER-1001",
    "recipient": { "name": "Jane Mwangi", "phone": "+254712345678" },
    "description": "Order #1001"
  }'
```

The quote already holds the buyer's pin and address, so you don't need to send them again. Book with the quote ID rather than trusting the fee from the browser: UrbnBox charges what the quote says.

## Test it

Use a `dpk_test_` key from a website on its list. You get real prices, marked `test`, and orders booked with a test secret key are never dispatched. The portal's **Checkout widget** page also has a live preview.

If the widget says the key does not work on this website, check that the exact origin (scheme and host, no path) is on the key.
