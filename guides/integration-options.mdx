All of these use API v2 underneath, so you can start with one and add another later.

| Option | Good for | You need |
| --- | --- | --- |
| [Shopify](/guides/shopify) | Shopify stores delivering in Nairobi | Owner or admin access to UrbnBox and Shopify |
| [WooCommerce](/guides/woocommerce) | WordPress stores | A secret key and a publishable key |
| [Checkout widget](/guides/checkout-widget) | Any website with its own checkout | A publishable key, and a server that books with a secret key |
| [API](/quickstart) | Order systems, marketplaces, warehouses, apps | A secret key |
| CSV on the portal | Occasional batches without code | A portal login |

## Questions worth answering first

**Who pays the delivery fee?** By default the buyer pays the driver on delivery. You can instead have UrbnBox take it from your wallet at booking (`merchant_wallet`) or out of the next cash remittance (`merchant_cod`). Contract customers can be invoiced monthly.

**Does the driver collect cash for your goods?** Set `collect_kes` on the order. UrbnBox pays it back to you the next morning, less any fees you owe.

**Where do orders start?** Most shops dispatch from one place. Save it on the portal's **Checkout widget** page and every short-form order starts there. If you dispatch from several places, send the pickup as a stop on each order.

**Do you need to know when an order is delivered?** Add a [webhook](/api-reference/webhooks).
