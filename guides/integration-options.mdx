Start with the integration that matches the system you already operate.

| Integration | Setup | Credential | Use it when |
| --- | --- | --- | --- |
| Vendor API: delivery orders | Your backend | Vendor API key | You want UrbnBox riders to deliver your orders to customers |
| Shopify Connect | UrbnBox dashboard | Shopify OAuth | Your store runs on Shopify |
| WooCommerce | WordPress plugin | Secret key | Your store runs on WooCommerce |
| Partner API: pickup-point shipments | Your backend | Secret key | You run a storefront, marketplace or OMS and send parcels between towns |
| Checkout widget | Customer browser | Publishable key | Customers choose a pickup point at checkout, with minimal frontend code |

## Delivery orders

Use the Vendor API when your system should hand orders to UrbnBox for delivery.
Your backend creates each order with the customer's details and address, and
reads its status as it moves from confirmation to delivery. You can also check
a spreadsheet of orders before you send them.

<Card title="Create your first delivery order" icon="arrow-right" href="/quickstart">
  Create a vendor API key and make your first request.
</Card>

## Shopify

Shopify merchants should use **Connect Shopify** in the UrbnBox dashboard.
UrbnBox handles authorization, carrier-rate registration, and paid-order
webhooks automatically. You do not copy Shopify Admin API tokens into UrbnBox.
Shopify orders are delivered through UrbnBox pickup points.

<Card title="Connect Shopify" icon="shopify" href="/guides/shopify">
  See the merchant connection flow.
</Card>

## WooCommerce

Install the UrbnBox WooCommerce shipping plugin and configure your UrbnBox
credential in WordPress. The plugin offers pickup-point delivery at checkout.

<Card title="Install the WooCommerce integration" icon="wordpress" href="/guides/woocommerce">
  Configure the shipping method.
</Card>

## Pickup-point shipments

Use the Partner API when your application already has a trusted backend and
sends parcels between towns. Your backend can request a quote, create
shipments, retrieve shipment state, and receive signed UrbnBox lifecycle
webhooks.

This suits custom storefronts, marketplaces, mobile backends, ERP and OMS
platforms. You do not need a platform-specific UrbnBox plugin.

<Card title="Send a pickup-point shipment" icon="arrow-right" href="/guides/pickup-point-shipments">
  Create credentials and make your first request.
</Card>
