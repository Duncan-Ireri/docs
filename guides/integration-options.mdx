title: "Choose an integration"

---

Start with the integration that matches the system you already operate.

| Integration | Setup | Credential | Use it when |
| --- | --- | --- | --- |
| Shopify Connect | UrbnBox dashboard | Shopify OAuth | Your store runs on Shopify |
| WooCommerce | WordPress plugin | Secret key | Your store runs on WooCommerce |
| Partner API | Your backend | Secret key | You own a custom storefront, marketplace, OMS, or WMS |
| Vendor API | Your backend | Vendor API key | You want order, product, inventory, pickup, return, and shipment APIs |
| Checkout widget | Customer browser | Publishable key | You need a locker picker with minimal frontend code |

## Shopify

Shopify merchants should use **Connect Shopify** in the UrbnBox dashboard.
UrbnBox handles authorization, carrier-rate registration, and paid-order
webhooks automatically. You do not copy Shopify Admin API tokens into UrbnBox.

<Card title="Connect Shopify" icon="shopify" href="/guides/shopify">
  See the merchant connection flow.
</Card>

## WooCommerce

Install the UrbnBox WooCommerce shipping plugin and configure your UrbnBox
credential in WordPress.

<Card title="Install the WooCommerce integration" icon="wordpress" href="/guides/woocommerce">
  Configure the shipping method.
</Card>

## Custom ecommerce platforms

Use the Partner API when your application already has a trusted backend. Your
backend can request shipping quotes, create shipments, retrieve shipment state,
and receive signed UrbnBox lifecycle webhooks.

This is the preferred path for custom storefronts, marketplaces, mobile
backends, ERP systems, OMS platforms, and WMS integrations. You do not need a
platform-specific UrbnBox plugin.

<Card title="Integrate with the Partner API" icon="arrow-right" href="/quickstart">
  Create credentials and make your first request.
</Card>

## Vendor operations API

Use the Vendor API when the external system needs deeper commerce operations
such as orders, products, inventory adjustments, pickups, returns, bulk imports,
and webhooks.

<Card title="Explore the Vendor API" icon="brackets-curly" href="/reference-overview">
  Review the available API surfaces.
</Card>
