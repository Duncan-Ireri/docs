title: "API reference overview"
description: "Base URL, keys, conventions and endpoint groups for UrbnBox API v2."
---

Every endpoint is under one base URL:

```text
https://portal.urbnbox.io/api/v2
```

There is no v1. If you are moving an older integration, start with [Moving from v1](/guides/migrating-from-v1).

## Endpoint groups

| Group | Key | Purpose |
| --- | --- | --- |
| Quotes | Secret (`dk_`) | Price an order before booking it |
| Orders | Secret (`dk_`) | Book, batch, check a CSV, list, read, cancel, return |
| Stock and invoices | Secret (`dk_`) | Goods UrbnBox holds for you, and monthly invoices |
| Webhooks | Secret (`dk_`) | Endpoints that receive signed events |
| Checkout | Publishable (`dpk_`) | Delivery prices for the checkout widget, from allowlisted websites |
| Public | None | UrbnBox outlets |
| Shopify callbacks | Shopify signature | Rates and paid orders, called by Shopify |

## Conventions

- Send JSON with `Content-Type: application/json`. Field names are snake_case.
- Unknown fields are refused, so a misspelt field fails loudly instead of being ignored.
- Amounts are whole KES and end in `_kes`. Times are RFC 3339.
- `reference` is your own order number. It is unique per account and makes booking safe to retry.
- Lists come back wrapped: `{"orders": [...]}`, `{"stock": [...]}`.

## Errors

Every error has the same shape:

```json
{ "error": { "code": "rejected", "message": "only orders not yet dispatched can be cancelled; this one is scheduled" } }
```

| Status | Code | Meaning |
| --- | --- | --- |
| `400` | `bad_request` | Not valid JSON, or a field the endpoint doesn't know |
| `401` | `unauthorized` | Missing, unknown or switched-off key |
| `403` | `forbidden` | Publishable key used from a website not on its list |
| `404` | `not_found` | No such quote, order or webhook on your account |
| `422` | `rejected` | A business rule said no. The message is written for people and safe to show |
| `429` | `rate_limited` | Slow down and retry |
| `500` | `internal` | Retry with the same `reference` |
