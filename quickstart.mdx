title: "Quickstart"
description: "Price an order, book it and track it with API v2 in a few minutes."
---

This walks through the three calls most integrations need: a quote, an order, and reading the order back. Use a test key while you build; test orders are never dispatched or charged.

## 1. Make a secret key

Sign in to the UrbnBox portal, open **Integrations** and create a **Secret** key. Choose **Test**. Copy it straight away; it is shown once.

```bash
export URBNBOX_KEY="dk_test_..."
```

<Warning>
  A secret key books orders on your account. Keep it on your server, never in a browser, app or repository.
</Warning>

## 2. Get a price

Every order is booked against a quote, which fixes the price for 24 hours.

```bash
curl https://portal.urbnbox.io/api/v2/quotes \
  -H "X-API-Key: $URBNBOX_KEY" \
  -H "Content-Type: application/json" \
  -d '{"kind": "delivery", "vehicle_class": "rider", "distance_km": 7.5}'
```

```json
{
  "id": "4f1c2b0e-...",
  "kind": "delivery",
  "vehicle_class": "rider",
  "total_kes": 350,
  "test": true,
  "expires_at": "2026-11-06T09:30:00Z"
}
```

## 3. Book the order

Send the quote ID, your own order number as `reference`, and who to deliver to. UrbnBox collects from the dispatch point saved on your account.

```bash
curl https://portal.urbnbox.io/api/v2/orders \
  -H "X-API-Key: $URBNBOX_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "quote_id": "4f1c2b0e-...",
    "reference": "ORDER-1001",
    "recipient": { "name": "Jane Mwangi", "phone": "+254712345678", "address": "Kilimani, Nairobi" },
    "description": "2 cartons",
    "collect_kes": 2400
  }'
```

`collect_kes` is cash the driver collects for your goods; leave it out if the buyer has already paid you. The response is the order, with an `id`, a `status` of `booked` and a `tracking_url` your recipient also gets on WhatsApp.

<Tip>
  `reference` makes booking safe to retry. Sending the same reference again returns the order you already booked instead of a second one.
</Tip>

## 4. Follow it

```bash
curl https://portal.urbnbox.io/api/v2/orders/ORDER_ID -H "X-API-Key: $URBNBOX_KEY"
```

An order moves through `booked`, `scheduled` (on a vehicle), `in_progress` (picked up) and `completed`, or ends `cancelled` or `failed`. Rather than polling, add a [webhook](/api-reference/webhooks) and UrbnBox will tell you as it happens.

## Going live

When UrbnBox has approved your account, create a **Live** secret key and swap it in. Nothing else changes.
